Library Books Management System
- A python based library books management system developed to manage and organise library books records.

Features
- Add library books
- View available books
- Search for books
- Manage books records
- Test system functionality

Technology used 
- Python
- Python testing

Project Structure 
Code.py - Main application code 
Test.py - Testing code 
README.md - Project documentation

Purpose 
- This project was created to develop practical programming skills and demonstrate the use of Python to build a simple library management system.

SKills Demonstrated
- Python Programming
- Problem Solving
- Software Testing
- Basic Application Development
- Code Organization
